# Recurso original INDART3D

PNG original INDART3D recibido e incorporado; no es TUMAKER ni una reconstrucción.

Ruta prevista: `branding/INDART3D.png`. Registrar su SHA256 aprobado en `distribution/config.json` como `logo_sha256`. Sin ambos, la distribución final y su publicación se bloquean. El modo `allow_unbranded` es sólo para ensayar código y nunca para una versión definitiva.

El proceso copia exactamente el original horizontal de 1024×600, sin transformarlo. Comprueba el resultado en la pantalla real. No se genera personalización de otras orientaciones.
